# RFID & Fingerprint Lock System using Arduino

This project was developed for the **Computer Peripheral and Interfacing Sessional (CCE 322)** course. It demonstrates an integrated security lock system using Arduino, featuring both RFID and Fingerprint sensor modules.

## Features
- **RFID Access:** Allows users to scan registered RFID tags/cards to unlock.
- **Fingerprint Access:** Integrates a fingerprint scanner for biometric security.
- **LCD Display:** Shows real-time status and prompts over an I2C LCD.
- **Hardware Integration:** Demonstrates interfacing multiple peripherals (Sensors, LCD, Motors/Relays) with Arduino.

## Technologies Used
- **Microcontroller:** Arduino Uno/Nano
- **Sensors:** RFID (MFRC522), Fingerprint Sensor (e.g., R307)
- **Language:** C++ (Arduino IDE)
- **Libraries:** LiquidCrystal_I2C, Adafruit_Fingerprint, MFRC522
